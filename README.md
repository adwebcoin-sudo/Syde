# Nabd Copy Server

سيرفر بسيط لربط حسابات المشتركين (على أي بروكر) بنسخ صفقات حساب الماستر تلقائيًا، باستخدام MetaApi CopyFactory.

## الخطوات بالترتيب (كل ده ممكن تعمله من الهاتف عبر متصفح عادي)

### 1) جهّز حساب MetaApi
1. سجّل في https://app.metaapi.cloud
2. من `app.metaapi.cloud/token` انسخ الـ API Token
3. من `app.metaapi.cloud/accounts` أضف حساب MT5 بتاع الماستر (الروبوت) — احتفظ بمعرف الحساب (Account ID) اللي هيظهر بعد الإضافة

### 2) ارفع الكود على GitHub
1. أنشئ مستودع (repository) جديد فاضي على github.com
2. ارفع محتوى هذا المجلد بالكامل إليه (تقدر تستخدم تطبيق GitHub أو رفع الملفات مباشرة من متصفح الهاتف)

### 3) انشر على Render
1. سجّل على https://render.com (فيه خطة مجانية تكفي للبداية)
2. اختر **New → Web Service** واربطه بمستودع GitHub اللي رفعته
3. في إعدادات البيئة (Environment Variables) أضف:
   - `METAAPI_TOKEN` = التوكن اللي جبته من الخطوة 1
   - `MASTER_ACCOUNT_ID` = معرف حساب الماستر
   - `STRATEGY_NAME` = أي اسم تحبه للإستراتيجية
4. اضغط Deploy — بعد انتهاء البناء هتاخد رابط عام زي:
   `https://nabd-copy-server.onrender.com`

### 4) أول تشغيل
بعد أول تشغيل ناجح، افتح سجلات (Logs) الخدمة على Render وابحث عن سطر:
```
تم إنشاء إستراتيجية جديدة: xxxxxxxx
```
انسخ هذا المعرف وأضفه كمتغير بيئة جديد `STRATEGY_ID` على Render، عشان السيرفر ميعملش إستراتيجية جديدة في كل مرة يعيد التشغيل.

### 5) اختبار الاشتراك
من أي مكان (أو من نموذج تسجيل على موقعك) ابعت طلب POST لـ:
```
https://your-app.onrender.com/subscribe
```
بالبيانات:
```json
{
  "login": "12345678",
  "password": "investor-or-trade-password",
  "server": "اسم سيرفر البروكر الخاص بالمشترك",
  "platform": "mt5",
  "riskRatio": 1,
  "name": "اسم المشترك"
}
```

## تنبيهات أمان مهمة
- هذا السيرفر يستقبل **بيانات دخول حساب تداول حقيقي**. لازم:
  - تشغيله دائمًا عبر HTTPS (Render بيوفر ده تلقائيًا)
  - عدم تخزين كلمات المرور في أي قاعدة بيانات نصية عندك — الكود الحالي يمررها مباشرة لـ MetaApi ولا يحفظها محليًا
  - إضافة مصادقة (API key أو تسجيل دخول) على نقطة `/subscribe` قبل إطلاقها للعامة، لمنع أي شخص من استخدامها عشوائيًا
  - يُفضّل طلب "Investor Password" (كلمة مرور القراءة فقط) بدل كلمة المرور الحقيقية إن كانت الإستراتيجية تسمح بذلك — لكن CopyFactory يحتاج صلاحية تنفيذ صفقات فعلية على حساب المشترك، فهنا الأمر يعتمد على صلاحيات النسخ نفسها
- استشر شروط الخدمة في بلدك: إدارة تنفيذ صفقات نيابة عن مستخدمين آخرين قد تصنَّف قانونيًا كـ"إدارة أموال" وتحتاج ترخيصًا في بعض الدول — راجع هذه النقطة قبل تسويق الخدمة تجاريًا.
